Getting started

From download to your first meeting in ten minutes.

MidMeeting records your microphone and your computer's sound as two separate tracks, so every line of the transcript is labelled You or Them, never guessed at. AI advisors you pick read along and leave a note on your screen when something is worth catching. They never talk in the call. Nothing leaves your computer except the text sent to the AI you choose.

Step 1. Install.

Pick your platform and run the installer. Three free meetings, any length, no card required.

Windows

Download the Windows installer for Windows 10 or 11, 64-bit, and run it. The installer is not signed yet, so SmartScreen will warn on first launch: click More info, then Run anyway.

macOS

Download the macOS build for Apple Silicon, macOS 14.4 or later. It is signed and notarized, so it opens normally.

Linux

Download the AppImage, make it executable, and run it. It works on Ubuntu 22.04 and later and on any modern distro. A .deb package is also available.

Step 2. The transcription model.

On first launch, MidMeeting downloads a model that turns speech into text on your own computer. Pick one from the list: the smallest is 75 MB and gets you talking right away. You can replace it with a bigger, more accurate model later in Settings, no reinstall needed.

Step 3. Pick who reads along.

The advisors need an AI to think with. There are a few ways to give them one: a cloud provider with an API key, which is the simplest choice for most people; a model running on your own computer, which is free and private but needs a capable machine; the agent bridge, for people who already run Claude Code, Codex or another agent CLI and want it to sit in on the meeting; or nothing at all, if you only want the transcript (choose No advisor, you can change it later in Settings).

OpenRouter, recommended

One account gets you every model, priced pay as you go.

  1. Open OpenRouter's key page and sign in or create an account.
  2. Click Create key, give it any name, and leave the limit empty.
  3. Copy the key. It starts with sk-or-. Paste it in MidMeeting.

Add a few dollars of credit under Credits; you pay per use, and every model is priced on their site. Some models are free with a daily cap.

Anthropic

Claude models.

  1. Open Anthropic's key page and sign in or create an account.
  2. Click Create Key and give it any name.
  3. Copy the key. It starts with sk-ant-. Paste it in MidMeeting.

Add credit under Billing first; you pay per use.

OpenAI

GPT models.

  1. Open OpenAI's key page and sign in or create an account.
  2. Click Create new secret key and give it any name.
  3. Copy the key. It starts with sk-. Paste it in MidMeeting.

Add credit under Billing first; you pay per use. This is separate from a ChatGPT subscription.

Google Gemini

Gemini models, free tier available.

  1. Open Google's key page and sign in or create an account.
  2. Click Create API key.
  3. Copy the key. It starts with AIza. Paste it in MidMeeting.

There is a free tier with daily limits; paid use needs billing on the Google Cloud project.

xAI

Grok models.

  1. Open xAI's key page and sign in or create an account.
  2. Under API Keys, click Create API key.
  3. Copy the key. It starts with xai-. Paste it in MidMeeting.

Add credit first; you pay per use.

A model on this computer

Free and private, no key to buy, nothing sent anywhere. Needs a capable machine.

  • LM Studio. Start the server in the Developer tab, then load a model. Default address http://localhost:1234/v1.
  • Ollama. Run ollama serve. Default address http://localhost:11434/v1.

An empty answer means the model's reasoning needs to be turned off, or that a smaller model should be picked instead.

Agent bridge

Your own agent reads the transcript and writes the notes, using everything it already knows about your repos, your notes and your tools. Install the MidMeeting skill in the agent you use, then tell it to join the meeting: the full guide with copy-paste commands is on the agent bridge page.

Step 4. Your first meeting.

Press Start recording when the call begins, and stop it when it ends. Watch the two meters while you talk: the one marked You is your microphone, the one marked Them is your computer's sound. Highlight any words in the transcript to ask the advisors about them. The Agents tab is where you pick who reads along, and four are ready to go.

Step 5. Three meetings on us.

The first three meetings are free, any length. After that, MidMeeting is $39 USD, once, for up to three computers. Nothing expires and there is nothing to cancel. See the pricing details.

If something goes wrong

The key was refused

Copy the key again, making sure you get the whole string with no extra spaces, and check that the provider account has credit.

MidMeeting could not reach the provider

This is usually a connection problem. Check that you are online and try again.

The model answered with no text

Pick another model in Settings. On a model running on your own computer, turn its reasoning off or choose a smaller model.

No words appear in the transcript

The transcription model is probably still downloading. Check its progress in Settings.

The Them meter is flat

That is normal until someone else in the call has spoken. It fills in as soon as their audio comes through.
