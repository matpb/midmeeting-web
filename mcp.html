MCP server

Ask your AI about any meeting you recorded.

MidMeeting 2.0 has a built-in MCP server. Turn it on, connect the AI client you already use, and it can search and read your meetings: transcripts, summaries, action items, the notes you typed and the cards your advisors left. It only reads, it runs on your own computer, it needs no account, and it is part of the free version.

Step 1. Turn it on.

Open MidMeeting, go to the MCP tab, and switch on "Let AI agents read my meetings". It is off until you do. Switch it off again and every connected client loses access at once.

  • Read-only: an AI client can search and read, never change or delete.
  • It reads transcripts, summaries, action items, advisor cards and every note you typed, private notes included.
  • It runs on your computer, only while an AI client is using it. No account, no open port, nothing listening on the network.
  • What an AI client reads is sent to the AI service behind that client, the same as anything else you show it.
  • It works with MidMeeting closed, because it reads the meeting library directly.

Step 2. Connect your AI client.

The MCP tab lists the AI clients it finds on your computer. Press Install next to yours and you are done. Each client below also has a one-line command, and a block to paste by hand.

In the blocks to paste, replace HELPER with the full path of the helper on your computer. The MCP tab shows every block with your own path already filled in, and so does midmeeting-bridge mcp config cursor (or any client name from this page).

PlatformHELPER is
Linux/home/YOU/.local/share/MidMeeting/bin/midmeeting-bridge
macOS/Users/YOU/Library/Application Support/MidMeeting/bin/midmeeting-bridge
WindowsC:\Users\YOU\AppData\Roaming\MidMeeting\bin\midmeeting-bridge.exe

MidMeeting installs the helper the first time it opens and keeps it up to date. In JSON on Windows, write each backslash twice.

Claude Code

In a terminal:

$ midmeeting-bridge mcp install claude-code

Or by hand:

claude mcp add --scope user midmeeting -- "HELPER" mcp

Check: In Claude Code, type /mcp and look for midmeeting.

Codex

In a terminal:

$ midmeeting-bridge mcp install codex

Or by hand:

command = 'HELPER'
args = ["mcp"]

Any other MCP client

MidMeeting speaks standard MCP over stdio. Most clients accept the JSON below; the rest ask for three values.

{
  "mcpServers": {
    "midmeeting": {
      "command": "HELPER",
      "args": ["mcp"]
    }
  }
}
Transport: stdio
Command: HELPER
Arguments: mcp

Check: Call the status tool: it says whether access is on.

To undo any of these, press Remove in the MCP tab, or run midmeeting-bridge mcp uninstall cursor with your client's name.

Step 3. Ask.

Talk to your AI the way you already do. It decides when to look in your meetings.

Search my meetings for what we decided about pricing.
Summarize my last meeting and list the action items.
What did I promise to do in my meetings this week?

What your AI can do.

ToolWhat it does
statusSays whether access is on, and how many meetings the library holds.
list_meetingsLists meetings, newest first, filtered by date or by words in the title.
search_meetingsSearches every transcript, note, summary, action item, advisor card and title, and returns the best passages with their timestamps.
get_meetingOne meeting at a glance: its summary, action items, notes and cards.
get_transcriptThe transcript with timestamps: all of it, one speaker, or a time range. Long meetings come in pages.
get_summaryThe summary MidMeeting saved for a meeting.
get_action_itemsAction items for one meeting, or for every meeting in a date range.
get_notesThe notes you typed, each at the moment you typed it.

Search that finds it

Search ignores case and accents and forgives small typos, so "kubernets" still finds Kubernetes. Use quotes for an exact phrase, a minus sign to leave a word out, and a star for a prefix:

"renewal date" -draft

budget* Sanjay

réunion produit

Narrow it by date, by meeting, by who was speaking (you or them), or by where to look: transcript, notes, summary, action items, cards or title.

Who said what

MidMeeting labels two voices: You, which is your microphone, and Them, which is everyone you hear through the computer. It does not name the people on the call, and the server tells your AI not to guess.

Privacy, plainly.

Off by default. Until you switch it on, the server answers one question only: that access is off.

It cannot change anything. The meeting library is opened read-only. There is no tool that writes, renames or deletes.

The server runs on your computer. Your AI client starts the helper and talks to it directly. There is no server on the network, no port, no account and no MidMeeting cloud.

Your AI still sees what it reads. A passage your AI client reads goes to the AI service that client uses. That includes private notes: private keeps a note away from your advisors, not from an AI client you connected yourself.

For developers.

The server is midmeeting-bridge mcp, speaking JSON-RPC over stdin and stdout. It implements the MCP specification of 2026-07-28 and still answers clients that open with initialize. Every tool is annotated read-only, non-destructive, idempotent and closed-world, declares an output schema, and returns structured content alongside the same JSON as text. Lists are paged with opaque cursors. Each meeting is also a resource: midmeeting://meetings/{meeting_id}, with /transcript, /summary and /action-items beneath it.

$ midmeeting-bridge mcp --help

$ midmeeting-bridge mcp status

$ midmeeting-bridge mcp clients

$ midmeeting-bridge mcp config claude-desktop

If something is off.

Your AI says access is turned off

Open MidMeeting, go to the MCP tab and switch it on. No restart is needed on either side.

The terminal cannot find midmeeting-bridge

Open MidMeeting once, then open a new terminal. If it is still missing, use the full path from the table in step 2.

The client does not list midmeeting

Most clients read their MCP settings only when they start. Quit the client completely and open it again.

It finds no meetings

The server reads the meetings recorded on this computer. Record or import one in MidMeeting first.

Limits.

Words, not audio. The server gives your AI text. It does not play or send recordings.

It searches words. Search matches the words that were said, with typo and accent tolerance. Your AI supplies the synonyms.

Reading only. Renaming, deleting and recording stay in the app.
